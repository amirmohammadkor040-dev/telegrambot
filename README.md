# بات صندوق پیام تلگرام

این بات به افراد اجازه می‌دهد به شما پیام بدهند. هر پیام (متن، عکس، فایل، ویس و …) همراه با نام، نام کاربری و شناسهٔ فرستنده، به حساب تلگرام شما فوروارد می‌شود.

## راه‌اندازی

1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید، دستور `/newbot` را اجرا کنید و توکن بات را دریافت کنید.
2. شناسهٔ عددی تلگرام خود را از [@userinfobot](https://t.me/userinfobot) بگیرید.
3. فایل تنظیمات را بسازید و مقادیرش را وارد کنید:

   ```bash
   cp .env.example .env
   ```

4. متغیرهای فایل `.env` را به محیط اجرا صادر کنید و وابستگی‌ها را نصب کنید:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   set -a; source .env; set +a
   python bot.py
   ```

5. لینک `https://t.me/USERNAME_BOT` را برای دیگران بفرستید. کاربر با `/start` و سپس ارسال پیام، پیامش را برای شما می‌فرستد.

## نکات امنیتی

- فایل `.env` در گیت نادیده گرفته می‌شود؛ توکن بات را در کد یا مخزن عمومی قرار ندهید.
- ابتدا یک‌بار خودتان به بات پیام دهید تا تلگرام اجازهٔ ارسال پیام‌های اعلان به حساب شما را داشته باشد.
- این نسخه از **long polling** استفاده می‌کند؛ تا زمانی که `python bot.py` در حال اجراست، بات پاسخ می‌دهد.
